APEX ELITE FC — REQUIRED API PATCH
===================================

IMPORTANT
---------
This patch is for the CURRENT api.mjs in your GitHub repository. It does not replace
the API file. Keep a copy of the original before editing. The existing API currently
has a master code and a basic staff code; it does NOT yet implement a separate coach
role. The Coach Admin page will not work until these server-side changes are made.

1) In the public "site" response, also keep coachCode private.
Find:
  const{players,pays,orders,code,staffCode,next,...pub}=s;
Replace with:
  const{players,pays,orders,code,staffCode,coachCode,next,...pub}=s;

2) Add the secure Main Admin recovery endpoint.
Find this line after the public sitemap/robots handlers:
  const b=await req.json().catch(()=>({}));

Immediately AFTER it, add:
  if(p==="admin-recovery"){
    if(req.method!=="POST")return J({error:"Method not allowed"},405);
    const expected=process.env.ADMIN_RECOVERY_CODE;
    const supplied=String(b.recoveryCode||"");
    const next=String(b.newAdminCode||"");
    if(!expected||supplied!==expected)return J({error:"Invalid recovery code"},401);
    if(next.length<12)return J({error:"New Main Admin code must be at least 12 characters"},400);
    s.code=next;
    await st().setJSON("state",s);
    return J({ok:true});
  }

In Netlify, add an environment variable named ADMIN_RECOVERY_CODE with a long, random private value (at least 32 characters). Do not put that value in GitHub or send it in chat. Redeploy after setting it. Then visit /admin-reset.html, enter the private recovery value and choose your own new Main Admin code. After success, DELETE public/admin-reset.html from GitHub. Keep the API recovery route protected by the secret; do not remove the environment variable.

3) Replace the authentication lines inside `if(p==="admin"){`
Find:
  const MC=s.code||process.env.ADMIN_CODE||"APEX2026",master=b.code===MC,staff=!master&&!!s.staffCode&&b.code===s.staffCode;
  if(!master&&!staff){await new Promise(r=>setTimeout(r,800));return J({error:"Wrong admin code"},401)}

Replace with:
  const MC=s.code||process.env.ADMIN_CODE||"APEX2026";
  const master=b.code===MC;
  const staff=!master&&!!s.staffCode&&b.code===s.staffCode;
  const coach=!master&&!staff&&!!s.coachCode&&b.code===s.coachCode;
  if(!master&&!staff&&!coach){await new Promise(r=>setTimeout(r,800));return J({error:"Wrong admin code"},401)}

4) Immediately AFTER the existing staff permission check:
  if(staff&&b.action!=="load"&&(!PM[b.action]||!perms[PM[b.action]]||(b.action==="player"&&(b.data||{}).del)))return J({error:"Only the master admin can do that"},403);

Add:
  const cd=b.data||{};
  if(coach&&b.action!=="load"){
    const allowed=["player","playerProfile","squad"];
    if(!allowed.includes(b.action))return J({error:"Coach Admin can only manage players, player SEO and formations"},403);

    if(b.action==="playerProfile"&&cd.del)return J({error:"Only the main admin can delete player profiles"},403);
  }

5) Add a coach-code management action inside the switch, near case "staff":
  case"coach":{
    const cc=String(d.code||"");
    if(d.clear){delete s.coachCode;break}
    if(cc.length<8||cc===MC||cc===s.staffCode)return J({error:"Coach code must be at least 8 characters and different from other codes"},400);
    s.coachCode=cc;
    break;
  }

6) Ensure the response at the end reports the role and hides sensitive information.
Find:
  const{code:_c,staffCode:_k,...out}=s;out.role=master?"master":"staff";out.perms=perms;out.hasStaff=!!s.staffCode;
Replace with:
  const{code:_c,staffCode:_k,coachCode:_cc,...out}=s;
  out.role=master?"master":coach?"coach":"staff";
  out.perms=perms;
  out.hasStaff=!!s.staffCode;
  out.hasCoach=!!s.coachCode;

With:
